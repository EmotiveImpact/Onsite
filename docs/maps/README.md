# ONSITE map designs

- [Heron Reach / 32-player design](heron-reach-32/README.md): a separate proposed estate with
  five height levels, sixteen home units, coordinated plans, a landscape/lighting layer and an
  editable Blender massing model. Target: 16v16; runtime integration and playtesting outstanding.
- [Existing Heron Court as-built plan](../development/evidence/as-built.svg): the smaller
  WWB-based playable already on main. [Its validation](../development/CURRENT-VALIDATION.md)
  describes that implementation, not the larger Heron Reach proposal.

Do not conflate concept art, metric proposals, Blender design renders and actual game evidence.
