# Dimensional shop interiors

This pass replaces The Corner's four shelf render instances with original, efficient Blender
shelving and real stock. The centre units now display goods on both sides; the existing rear
units still face north. Each shelf, package and tin stays inside its original 1.2 × 0.5 × 2.07 m
collision box. The unchanged fridge meshes supply the refrigerated-stock depth.

All three photographic interior cards are retired. The existing plaster walls now enclose the
actual rooms. The launderette and Washhouse keep their original washer/dryer/cage geometry;
small folded goods and unbranded bottles rest on existing washer tops. There is no added floor
furniture, fake room extension, navigation change or new light.

`assets/blender/heron-reach/shop-depth.blend` is the editable Blender 4.3.2 source generated by
`scripts/maps/art/build_heron_shop_depth.py`. The kit contains **7,944 triangles in six material
batches**. Its compressed GLB is **184,612 bytes**; raw GLB is 772,004 bytes. The original 1024²
lived atlas is reused; no new texture is generated. Geometry is authored through
`heron_art_mesh.Builder`, and GLB vertices already use world `x=mapX−72`, `y=mapY`, `z=mapZ−60`.

The integration contract is explicit:

| Existing render content | Action |
| --- | --- |
| `SHOP_SHELF_UNIT`, map (107.24, 56.52), y=0 | Hide this render placement only |
| `SHOP_SHELF_UNIT`, map (108.52, 56.52), y=0 | Hide this render placement only |
| `SHOP_SHELF_UNIT`, map (109.4, 52.5), y=0 | Hide this render placement only |
| `SHOP_SHELF_UNIT`, map (112.6, 52.5), y=0 | Hide this render placement only |
| `E-shop/interior / hr_shop_image_corner` | Hide the old Corner card node |
| `W-shops/interior / hr_shop_image_laundry` | Hide the old launderette card node |
| `C-store/interior / hr_shop_image_laundry` | Hide the old Washhouse card node |

Authored node names are also retained in GLTFLoader's `userData.name` when its object-name
sanitisation changes punctuation. Keep all old shell, collider, nav, fridge and washer placements.
Load `/models/heron-reach/heron-reach-shop-depth.glb` without another positional offset.

The new node groups are `depth/corner / <material>` and `depth/laundry / <material>`. Reuse
`HeronReachMaterials` for `hr_upvc_white`, `hr_steel_black`, and `hr_steel_galv`. Preserve the
embedded `hr_lived_atlas` material (opaque, roughness 0.78, metalness 0, emission factor 0.08).
Prefer the same atlas material instance already loaded by the lived kit to avoid a duplicate
decoded 1024² texture allocation. No new texture source or licence is needed: the atlas's
original procedural-art/font provenance remains in `public/materials/heron/lived/manifest.json`.

Shelf undersides and package contact edges use darker vertex colours. Tins have actual lids,
side walls and depth, and stock sits directly on modelled shelf decks. The previous lived-kit
interior panels, top-stock trays and image-card perimeter rails are removed from its generator
and regenerated asset, so there is no overlap. Its exterior trim, window notices, drains and
service fittings remain. The checkpoint retains the previous authored result.

Before saving, the new builder asserts every shelf's complete geometry against its original
collider bounds; washer-top detail is checked against the exact existing machine x/z footprint.
It also checks every generated polygon against the front route, full 2 m centre aisle and rear
frame clearance volumes. The authoritative placement list, bounds, hashes, budgets and passed
checks are in `assets/blender/heron-reach/shop-depth-manifest.json`. These are geometric checks;
the parent pass owns native browser screenshots and input-driven route verification.

`tests/heron-shop-depth.test.ts` independently decodes the shipped meshopt geometry, checks
every triangle against current runtime collider footprints and protected routes, verifies stock
on both sides of the centre unit and contact vertex colours, and rejects leftover lived-kit
shelf panels. It also exercises the exact replacement selector, shared-atlas/card-hide loader
behaviour and artifact hashes. All five tests passed with `npx tsx --test tests/heron-shop-depth.test.ts`.

Rebuild with:

```sh
blender -b --python-exit-code 1 --python scripts/maps/art/build_heron_shop_depth.py
blender -b --python-exit-code 1 --python scripts/maps/art/build_heron_lived_detail.py
```

Each builder invokes the repository's locked npm gltfpack with `-cc -kn -km -kv -vtf` after
raw export and writes the resulting size/hash manifest. Original Blender 5.2 files are preserved.
