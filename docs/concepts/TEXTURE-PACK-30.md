# ONSITE — 30 texture candidates

Thirty individual colour texture images for the estate and all-black character kit. Originals are preserved unchanged.

These generated images are base-colour candidates, not complete PBR material sets. Seamlessness, physical scale and lighting neutrality are not certified. Check repetitions on a large plane, reconcile pattern sizes, and remove baked shading before final use. Normal, roughness and any required metalness maps still need authoring.

The shutter has visible groove shading; fabric and gravel also contain apparent surface lighting. Avoid doubling that shading when adding normal maps. The grass needs colour tuning against the estate palette.

Use sRGB for colour maps in Three.js; normal, roughness and metalness maps use linear data. Intended coverage below is a modelling starting point, not a measured scan size.
