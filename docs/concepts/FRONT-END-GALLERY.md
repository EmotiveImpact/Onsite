# ONSITE — Kit, intro and menu concepts

15 concept stills extending the established ONSITE white-and-amber visual identity. Trainers are selectable cosmetic kit items alongside headwear, tops, gloves and bottoms. Black streetwear remains the default.

Proposed flow: intro → title → character → kit → borough → match setup → squad lobby → loading → gameplay → results. Pause/settings is available during gameplay.

These are generated visual concepts, not implemented menus. The borough map is illustrative; final geography and interface details need implementation review.
